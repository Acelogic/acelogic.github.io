Current work / Experimental

Aurora Silicon

My work with Aurora Silicon explores bringing Windows on ARM to Apple Silicon Macs: understanding the hardware, building the boot path, and developing the platform support and drivers Windows needs.

The project is experimental. Its public documentation and firmware repositories provide a starting point for following development.

  • C / ARM64
  • Firmware & drivers
  • Experimental

Port / Emulation

VibeStation5

An experimental PS4/PS5 runtime derived from SharpEmu, with native macOS, iPadOS, and Android targets. Work spans ARM64 interpretation, guest loading, graphics, audio, and input. Early compatibility research, not a general-purpose playable emulator.

  • Swift
  • Kotlin / C++
  • Experimental
