Aurora Silicon C

My work with Aurora Silicon explores bringing Windows on ARM to Apple Silicon Macs: understanding the hardware, building the boot path, and developing the platform support and drivers Windows needs. The project is experimental. Its public documentation and firmware repositories provide a starting point for following development.

VibeStation5 Swift

An experimental PS4/PS5 runtime derived from SharpEmu, with native macOS, iPadOS, and Android targets. Work spans ARM64 interpretation, guest loading, graphics, audio, and input. Early compatibility research, not a general-purpose playable emulator.
Port Emulation Kotlin / C++ 2026
Source

q1n1 C / Python

A fork of m1n1 retargeted from Apple Silicon to the ASUS Zenbook A16 (Snapdragon X2E). Firmware loads it as a UEFI application, it takes the machine at EL2 after ExitBootServices, and it serves m1n1's proxy protocol over its own USB stack so the hardware can be driven interactively from a host. It pairs with Snapintosh, which runs stock, unmodified XNU on top of it.
Firmware Current work AArch64 EL2 2026
Source Code Snapintosh

Beautiful, modern and opinionated Linux: an Arch and Hyprland desktop. I am on two Omarchy teams: M, bringing Omarchy to the Mac, and Dragon, bringing it to Snapdragon.
